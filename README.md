# Retail Sales Data Analysis | Excel

## 📌 Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel to understand business performance, identify sales trends, and generate meaningful insights.

## 🎯 Objectives
- Analyze overall sales performance.
- Compare revenue across different stores.
- Evaluate product sales and quantity.
- Identify monthly sales trends.
- Present key business insights through an Excel dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Excel Formulas
- Data Visualization

## 📊 Key Metrics
- Total Sales: ₹22,07,643.55
- Total Quantity Sold: 11,057
- Total Transactions: Approximately 2,000

## 📈 Analysis Performed
- Store-wise sales performance.
- Monthly sales trends.
- Product and category analysis.
- Quantity and revenue analysis.

## 💡 Key Insights
- Compared sales performance across four stores.
- Identified differences in store-wise revenue.
- Analyzed transaction and quantity patterns to understand business performance.

## 📁 Project Files
- `Retail_Sales_Analysis.xlsx` – Excel workbook containing the analysis and dashboard.
